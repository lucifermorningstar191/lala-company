# Lala Company

**Software Banate Hain, Paisa Wapas Nahi Dete**

Parody website of a classic early-2000s Indian IT company website, complete with:

- Flashy yellow & red banner
- "You are our 1,000,000th visitor" popup
- Visitor counter
- Site Under Construction
- Cheap and Best badge
- And all the other classics

Live site: https://lucifermorningstar191.github.io/lala-company/
